# Commafeed Extra

This is a fork of the official [CommaFeed](https://github.com/Athou/commafeed) project.

## Extra Features

- **Truncate articles:** Automatically shortens long articles in your feed so you can quickly scan through your unread items. This helps keep your feed tidy and easy to read without being overwhelmed by long text blocks.
- **Global Filtering expression:** Apply filter rules across all of your subscriptions at once. Feeds will automatically default to the Global Filtering expression located in your user settings, but you can easily override or disable this behavior on a per-feed basis for custom control.
